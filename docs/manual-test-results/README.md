# Praktiske testresultater

Her kan anonymiserte `.md`-notater fra faktisk Windows-test lagres.
Ingen praktisk Windows-godkjenning foreligger ved a1-leveransen.

Noter versjon, dato, operativsystem/Python, scenarier, observerte resultater
og avvik. Bruk TEST-data. Ikke ta med konto-ID, TestID, personopplysninger,
sertifikater, dokumentinnhold eller uredigerte skjermbilder av Oppsett.

Originale logger og kontospesifikk evidens beholdes lokalt. Ikke fyll ut
«bestått» uten faktisk gjennomføring. Se [testprosedyren](../TESTING.md).
